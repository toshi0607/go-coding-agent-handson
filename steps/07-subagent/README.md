# step 07: サブエージェント(Task tool)— コンテキスト分離という設計

「認証処理がどこに実装されているか調べて」という依頼を考えます。エージェントは list_files でファイルを洗い出し、候補を read_file で次々に読み、ようやく「auth/login.go にあります」と答えます。このとき親の履歴には、調査で読んだファイルの中身が**全部**積まれています。欲しかったのは結論の1行だけなのにです。

このstepでは、この問題を解く道具——サブエージェント(Task tool)を実装します。エージェントが、自分の分身に仕事を委任するツールです。

## この章で学ぶこと

- コンテキスト分離: 調査の過程を別の履歴に隔離し、結論だけを受け取る
- サブエージェントに「何を渡し、何を渡さないか」という設計の核心
- 再帰の禁止、承認の出所表示——分身を作るときの実務的な論点

## 前のstepから引き継いだもの

step 06の解答(コンテキスト管理)は埋まった状態で始まります。今回増えたのは:

- [agent/task_tool.go](agent/task_tool.go) — Task tool(課題)
- [main.go](main.go) — サブエージェントの組み立てと配線(実装済み。後述の論点が詰まっているので読んでください)

## Task tool の正体は「エージェントを作るツール」

発想は単純です。エージェントループもツール実行も、すでに `agent` パッケージにあります。だったら、**ツールの中から新しいエージェントを起動すればいい**。

```
親: task(prompt: "認証処理の場所を調べて。結論だけ返して")
  └ サブエージェント: まっさらな履歴で起動
      ├ list_files / read_file を何度でも実行(この履歴はサブのもの)
      └ 最終応答: "auth/login.go にあります"
親の履歴に積まれるのは、この最終応答の文字列だけ
```

サブエージェントが30回ツールを呼んでも、親のコンテキストは tool_result 1件分しか消費しません。これが**コンテキスト分離**で、サブエージェントの最大の存在意義です。

## 何を渡し、何を渡さないか

設計の核心はここです。

- **渡すもの**: prompt(タスクの説明)だけ
- **渡さないもの**: 親の会話履歴

親の文脈を知らないからこそコンテキストが軽くなります。裏返すと、promptには「サブエージェントが単独で作業を完遂できるだけの情報」をすべて書き込む必要があります。[agent/task_tool.go](agent/task_tool.go) の `Description` がLLMにそれを要求しているのを確認してください。「サブエージェントはこれまでの会話を一切知らないため、背景・対象・期待する出力形式をすべて含めよ」。ツールの説明文が、そのまま設計意図の表明になっています。

## main.go の3つの論点(実装済み)

サブエージェントの組み立ては [main.go](main.go) にあります。親との違いは3点だけです。

**1. Taskツール自身は持たせない(再帰の禁止)。** サブエージェントがさらにサブエージェントを起動できると、制御不能な再帰(fork爆弾のようなもの)につながります。ファクトリが渡すツールは `baseTools`(Taskツールを含まない)です。

ここにGoの罠がひとつあります。親のツールリストは `append(baseTools, taskTool)` と書いてはいけません。`baseTools` に容量の余りがあると、追記先がサブエージェント用クロージャの参照する配列そのものになりえます。新しいスライスを作る `slices.Concat` を使います。「今は実害がなくても、あとから要素を足したときに黙って壊れる」類のバグです。

**2. 出力は捨てる。** サブエージェントの途中経過まで画面に流すと、親の表示と混ざって読めなくなります。`Out: io.Discard` で捨てています(実物のエージェントは進捗表示に工夫を凝らす部分です)。

**3. 承認の質問に出所を付ける。** 出力を捨てた結果、サブエージェントがツールの承認を求めると、質問だけが文脈なしに画面に現れます。ユーザーは何に答えているのか分かりません。そこでサブエージェント用には「(サブエージェントからの要求)」を質問に前置する別の `Checker` を渡しています。「人に聞けないから自動拒否」という選択肢もありますが、それではサブエージェントは調査しかできなくなります。
