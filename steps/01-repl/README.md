# step 01: 対話ループ(REPL)— 会話の記憶はどこにあるのか

最初のstepでは、ツールを1つも持たない「ただのチャット」を作ります。ターミナルで入力を受け取り、Messages APIに投げ、応答を表示する。それだけです。

それだけですが、このstepには本書全体を貫く重要な事実が1つ埋まっています。**Messages APIはステートレスである**、ということです。

## この章で学ぶこと

- Messages APIの1往復(リクエストとレスポンスの形)
- 会話履歴という「状態」をエージェント側が持つこと
- LLM呼び出しをインターフェースで抽象化し、APIキーなしでテストする方法

## 会話の記憶はどこにあるのか

チャットアプリを使っていると、AIが「さっきの話」を覚えているように見えます。では、その記憶はどこにあるのでしょうか。

答えは「APIサーバーには無い」です。Messages APIは毎回のリクエストを独立に処理します。前回のやりとりを覚えていません。会話が続いているように見えるのは、**クライアントが毎回、会話履歴の全体を送り直している**からです。

```
1ターン目のリクエスト: [user: "私はGopherです"]
2ターン目のリクエスト: [user: "私はGopherです",
                        assistant: "こんにちは、Gopherさん!",
                        user: "私の名前を覚えていますか?"]
```

つまり「会話の記憶」の実体は、[agent/agent.go](agent/agent.go) の `history` スライスです。ユーザー入力を積み、応答を積み、その全体を毎回送る。この管理を怠ると、LLMは記憶喪失になります。

重要なのは、**ユーザー入力だけでなくアシスタントの応答も積む**ことです。応答を積み忘れると、LLMは「自分が前に何を答えたか」を知らないまま会話を続けることになります。1ターン目は普通に動くので、この積み忘れは気づきにくいバグになります。

## LLM呼び出しの境界

[llm/client.go](llm/client.go) は `Client` インターフェースを定義しています。

```go
type Client interface {
	Complete(ctx context.Context, params anthropic.MessageNewParams) (*anthropic.Message, error)
}
```

実装は2つあります。

- `AnthropicClient` — 本物。anthropic-sdk-go で実APIを呼びます
- `ReplayClient` — テスト用。あらかじめ用意したレスポンスJSONを順番に再生します

`ReplayClient` が保持するのはMessages APIのワイヤーフォーマット(実際にHTTPで返ってくるJSON)そのものです。SDKの `Message` 型は内部にJSONメタデータを持っていて、構造体リテラルで組み立てると `ToParam()` などが正しく動きません。「本物と同じJSONをUnmarshalする」ことで、本物と同じ挙動を再現しています。この仕組みのおかげで、**本書のすべての検証テストはAPIキーなしで動きます**。

リクエスト/レスポンスの型にSDKの型をそのまま使っているのも意図的です。独自型に包むと「Messages APIが実際どういう形をしているか」が見えなくなってしまうため、教材としてはあえて生のまま扱います。

## 課題

[agent/agent.go](agent/agent.go) の `Run` に `TODO(step01-1)` と `TODO(step01-2)` があります。

1. **TODO(step01-1)**: ユーザー入力を user メッセージとして履歴に積む
2. **TODO(step01-2)**: アシスタントの応答も履歴に積む

どちらも1行で書けますが、「なぜ両方必要なのか」を検証テストの失敗メッセージで確かめながら進めてください。

## 検証

リポジトリのルートで:

```bash
make check STEP=01
```

`TestHistoryCarriesAcrossTurns` は「2ターン目のリクエストに1ターン目の内容が全部含まれているか」を検査します。片方の積み忘れをピンポイントで検出します。

## 動かしてみよう(任意)

APIキーがあれば実際に会話できます。

```bash
export ANTHROPIC_API_KEY=sk-ant-...
go run ./steps/01-repl
```

「私の名前は◯◯です」→「私の名前を覚えていますか?」と聞いてみてください。履歴管理が正しければ覚えていますし、`TODO(step01-2)` を空のまま動かすと、LLMは直前の自分の発言すら知りません。
